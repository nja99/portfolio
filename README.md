## Design

I designed the site myself, with a focus on clean layout, smooth motion and accessibility:

- Scroll-driven animations, including sideways-scrolling project panels.
- A slowly turning dotted globe on the first screen, with arcs linking points across it, then an animated network background that reacts to your cursor.
- Light and dark themes.
- Readable for everyone: all text meets the highest contrast standard (WCAG AAA), and the site respects the "reduce motion" setting.
- Works on phones, tablets and desktops.

Built with React (function components and hooks), Tailwind CSS and Vite.
